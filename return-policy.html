Return Policy

This page describes the demo return policy for the Lumiqart project.

Return Window

Customers can request a return within 7 days of delivery for eligible products.

Eligibility

  • Product should be unused and in its original packaging.
  • Return requests may require order details and product photographs.
  • Opened or damaged products may be reviewed before approval.

Refund

After an approved return is received and checked, the refund will be processed according to the selected payment method.

Need Help?

Use the Lumiqart Help Center & Chat for return assistance.
